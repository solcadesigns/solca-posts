# Sprint LinkedIn · sept 2026 · plan de publicaciones

**Ventana:** lunes 25 ago 2026 → domingo 21 sep 2026 (4 semanas).
**Cadencia semanal:** teaser lunes · newsletter miércoles (página + LinkedIn) · carousel o infografía jueves. El blog SEO del lunes lo entrega el task `solca-blog-weekly-lunes` y queda fuera de este plan (se coordina, no se duplica).

Este documento es para editar. Los copies son borradores; los prompts de imagen/infografía son ejecutables tal cual con Nano Banana / Flux Pro / Midjourney respetando la paleta Solca.

---

## Convenciones operativas (fijas para todo el sprint)

**Dos tipos de post con propósito distinto — no mezclar:**

- **Teaser editorial (lunes):** mecánica curiosidad → pregunta en comentarios → respuesta con enlace. Cuerpo del post SIN CTA. SIN link en el cuerpo. Cuando alguien pregunte en comentarios, se responde con enlace a la landing correspondiente, con UTM (`utm_source=linkedin&utm_medium=comment&utm_campaign=<slug>`). Este mecanismo fue el que produjo el viral del 10-ago.
- **Post de producto (jueves y newsletter):** CTA explícito, link en el primer comentario (o cuerpo si el alcance lo permite), UTM en el cuerpo del link (`utm_source=linkedin&utm_medium=post&utm_campaign=<slug>`).

**Convención de slugs de UTM que usa este sprint:**
- Teasers: `teaser-vacantes-sep`, `teaser-regulatorio-sep`, `teaser-salarios-sep`, `teaser-ia-sep`
- Producto: `libro-msl-sep`, `libro-cr-sep`, `libro-pm-sep`, `cv-review-sep`, `quiz-match-sep`
- Newsletter: `nl-vacantes-sep-s1`, `nl-regulatorio-sep-s2`, `nl-salarios-sep-s3`, `nl-recap-sep-s4`

**Tono Solca (no negociable):**
- Sin emoji, español LATAM, sin "gratis"/"gratuito", sin "genuinamente/honestamente/straightforward".
- "Pharma" es branding; "farmacovigilancia" con F.
- Audiencia = ciencias de la salud (no solo PhD). Cero exageraciones. Cero cifras sin fuente.
- Colección en expansión (no trilogía cerrada). Cualquier mención a los libros deja espacio para nuevos títulos.

**Paleta y tipografía visual (aplica a todo asset visual del sprint):**
- Fondo off-white `#F7F5EE` (nunca blanco puro).
- Navy `#1B3A6B` para elementos primarios.
- Naranja `#E8743A` para highlights.
- Azul medio `#2A6BAC` para acentos secundarios.
- Space Grotesk uppercase para headers, Inter para cuerpo.
